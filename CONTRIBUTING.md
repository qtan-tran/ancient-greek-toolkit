# Contributing to ancient-greek-toolkit

Thank you for helping! The toolkit lives on the community reporting new tools and dead links. All content contributions are **CC BY-SA 4.0**, code is **MIT**.

## The fastest ways to contribute

1. **Report a dead link:** open an issue with the broken link and, if you know it, the replacement. This is the single most valuable contribution – curated links survive only through reports from people actually using them.
2. **Suggest a new tool:** open an issue labelled `tool`, including a 1–2 sentence "use it when…" description. Acceptance checklist (see `docs/ROADMAP.md`): free or public domain · stable · genuinely useful for self-taught learners · verified link.
3. **Extend the resource comparisons:** take an issue labelled `comparison` – follow the policy in `docs/COMPARISONS.md`: link-only for copyrighted works, no hosting, no quotation of contents.

## PR process

1. Fork → branch → edit → PR. Short description: what and why.
2. When editing `index.html`, update `tools.json` in the same PR (and vice versa) – the two sources must stay in sync.
3. Every new link in a PR must be verified (HTTP check) before submitting.

## Community principles

- Remember the audience: self-taught learners of Ancient Greek – write "use it when…" for them, not for experts.
- Do not submit paid tools (not even "cheap and good") – this is a condition of the project's existence.
- Do not host copyrighted content; reviews of copyrighted resources stay link-only.
- The working language of this repository is **English**; keep grammatical terminology standard and searchable.
